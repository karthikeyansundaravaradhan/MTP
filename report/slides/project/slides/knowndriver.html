C5 · Known-driver splits

Training on the test driver inflates the score, not the skill

Random or epoch splits: 0.91 / 0.80, yet a model with no video scores 0.93 / 0.87

Known driver, new drive: 0.41, below the unseen-driver 0.45

So 90%+ within-subject results on similar data are recording recognition

19

A question we were asked: what if we split each driver’s data between train and test? The score jumps to 0.91 with random windows and 0.80 with whole held-out epochs. But a logistic regression that sees no video, only who, which drive and when, scores even higher. Within a drive, drowsiness is nearly a smooth function of time, so seeing part of a drive gives away the rest. The realistic version, a known driver on a new drive, scores 0.41, below unseen drivers, because the model learns this face means that drive’s KSS level.
